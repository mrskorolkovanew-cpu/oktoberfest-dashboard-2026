# Октоберфест 2026

Статический дашборд подготовки фестиваля 23–25 октября 2026 года в парке «Сказка».

## Разделы

- Обзор: бюджет, готовность задач, ближайшие контрольные точки, 900 купонов по видам и дням, 18 подарочных билетов и пять сортов пива.
- График задач: 32 задачи, сроки, статусы и точные примечания из Excel.
- Программа: мероприятия трёх дней, призы, ассортимент и описание активностей.
- Тайминг: 16 мероприятий, отдельные локации, часы трёх дней и фильтры.
- Бюджет: встроенный Excel и исходный файл для скачивания.
