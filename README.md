# Октоберфест 2026 — дашборд подготовки

Статический веб-дашборд проекта «Октоберфест 2026».

В нём собраны ключевые показатели, статусы задач, контрольные даты, программа и открытые вопросы проекта.

## Карта источников

| Раздел дашборда | Основной источник |
| --- | --- |
| Обзор: показатели бюджета | `Бюджет Октоберфест.xlsx` |
| График задач | `График_подготовки_Октоберфест.xlsx` |
| Программа мероприятий | `Прил.1 к Плану_Программа Октоберфест полная_.docx` |
| Обзор: цель, сроки, ограничения и риски | `PMO-01_02_Brif_Oktoberfest.docx` |
| Контрольные точки | `26.10.01_Фестиваль Октобер Фест от 02.09.26_План задач .docx` |
| Тайминг по дням и локациям | `Октоберфест_тайминг_по_дням_2026-10-23_25.xlsx` |

`Программа Октоберфест полная.docx` используется только как вспомогательный источник, если не противоречит Приложению 1.

## Локальный просмотр

Откройте <code>dist/index.html</code> в браузере или запустите из папки проекта любой локальный HTTP-сервер.

## Публикация

В репозитории предусмотрен GitHub Actions workflow для GitHub Pages. После создания репозитория включите GitHub Pages с источником **GitHub Actions**.

## Актуализация 2026-10-13

Публикуется папка `dist`. Источники сверены с текущими файлами проекта в Nextcloud. Доход — 12 500 000,00 ₽, затраты — 5 123 008,94 ₽, прибыль — 7 376 991,06 ₽, по формулам бюджета. Бриф версии 5.0: бюджет не утверждён.

Вкладка «Тайминг» содержит все 18 строк Excel с отдельными локациями, тремя днями, фильтрами по дню и месту, пояснениями общих блоков и условного ночного сеанса. Копия Excel доступна для скачивания. При расхождениях старого дневного раздела плана используются актуальный файл тайминга и прямые уточнения пользователя. Исходные рабочие DOCX в репозиторий не добавляются.

Программа дополнена точными таблицами купонов и билетов из Приложения 1, пятью сортами пива, блюдами, механиками восьми активностей и четырёх детских МК. Повторно загружен обновлённый график подготовки: 18 билетов совпадают с планом и программой. Расхождения по часам ведущего и составу итоговой формулы бюджета показаны отдельно без изменения источников.

Повторно загружен обновлённый бриф версии 5.0: добавлено подготовленное предложение для сотрудничества с блогерами; скидочные купоны включены в допустимые призы. Подготовка предложения не означает заключённые договорённости с блогерами.


На главной странице показаны виды и количество всех 900 купонов и 18 билетов по дням, а также пять сортов пива с характеристиками. Блоки «Обновлённый бриф» и «Карта работ» удалены по запросу пользователя.
